# AGENTS.md — chisel/docs

Starlight (Astro 7) docs site. Source lives under `src/content/docs/`.

## Working on this site

- Package manager: **bun**.
- Start dev server in background mode: `bun run dev`. Don't run a foreground dev server.
- Don't hand-edit generated reference pages. `reference/python-rules.md` and `reference/js-rules.md` are regenerated by `scripts/sync-rules.mjs` on every build.
  - JS rules come from invoking the `chisel-js` CLI in `../chisel_js` — edit the rule's `describeRules()` there, not the page.
  - Python rules still come from the `scripts/data/py-rules.json` snapshot; refresh it after a release with `chisel rules --json > scripts/data/py-rules.json`.
