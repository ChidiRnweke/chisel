import { Card, CardGrid } from '@astrojs/starlight/components';

**The agent writes. Chisel checks. Every violation points to the skill that teaches the pattern.**

<CardGrid>
  <Card title="Deterministic, not vibes" icon="approve-check">
    No scoring, no LLM judge. `chisel check .` returns the same violations
    every run, each with its fix. An agent can't argue with it, and
    neither can a flaky reviewer.
  </Card>
  <Card title="Skills read when they matter" icon="open-book">
    You don't have to hope the agent reads your docs up front. The check
    runs after the code is written, and every violation names the bundled
    skill that teaches the pattern it skipped.
  </Card>
  <Card title="One rulebook, both stacks" icon="puzzle">
    `chisel` for Python backends, `chisel-js` for TypeScript frontends.
    Same rule shape, same JSON output, same architectural intent.
  </Card>
</CardGrid>

<CardGrid>
  <Card title="chisel" icon="seti:python">
    Python · FastAPI backends
    ```sh
    pip install chisel
    chisel check .
    ```
  </Card>
  <Card title="chisel-js" icon="seti:typescript">
    TypeScript · SvelteKit frontends
    ```sh
    npm install -g chisel-js
    chisel-js check .
    ```
  </Card>
</CardGrid>

## What it catches

<CardGrid>
  <Card title="Import boundaries">
    `services` never import `sqlalchemy`. ORM types stay in repositories.
  </Card>
  <Card title="Structural invariants">
    `getattr`/`setattr` banned, dataclasses use `slots=True`.
  </Card>
  <Card title="Component & colour rules">
    Raw HTML tags must use shadcn replacements, arbitrary Tailwind values banned.
  </Card>
  <Card title="Reactivity rules">
    `$effect` without cleanup flagged, `onMount` must touch a browser API.
  </Card>
  <Card title="Complexity limits">
    Route handler ≤ 20 LoC, page ≤ 100 LoC.
  </Card>
  <Card title="Testing discipline">
    One assert per test, mocking libraries banned.
  </Card>
</CardGrid>
